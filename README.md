# 鱼灾屏蔽助手

一款用于 Bilibili 视频和番剧页面的 Chrome 扩展：在当前浏览器页面本地隐藏低等级评论，以及用户名或评论内容命中自定义关键词的评论/回复。

> 过滤只影响你自己的页面显示，不会删除评论、屏蔽账号、提交举报或修改 B 站数据。

## 功能

- 隐藏可识别等级低于 3 级的评论和回复。
- 检查评论用户名、正文和组件显示文本，命中任一关键词时隐藏对应评论/回复。
- 在扩展弹窗中分别启停总过滤、等级规则和关键词规则。
- 在弹窗中编辑关键词，支持中文逗号、英文逗号和换行分隔。
- 适配 B 站新版 Shadow DOM 评论组件，并兼容部分旧版评论区结构。
- 页面右下角显示运行状态、检查数量和隐藏数量。
- 关键词及开关设置保存在 Chrome Sync Storage 中。

## 默认过滤规则

默认开启两类过滤：

1. **等级过滤：** 隐藏能识别且等级小于 3 的评论。无法识别等级时，不会仅因为等级缺失而隐藏。
2. **关键词过滤：** 评论用户名或内容包含任一默认关键词时隐藏。

默认关键词如下：

```text
本鱼、本肥鱼、肥鱼、大肥鱼、小肥鱼、肥肥鱼、鱼鱼、鱼鱼我呀、鱼宝、鱼宝贝、小鱼、小鲸鱼、鲸鱼、本鲸、鱼主人、鲸鱼主人、主人、主人大人、我的主人、本鱼觉得、本鱼认为、本鱼表示、本鱼来啦、鱼鱼来啦、DeepSeek、Deep Seek、深度求索、DeepSeek-R1、DeepSeek-V3
```

关键词采用不区分英文大小写的“包含匹配”。例如设置“鲸鱼”，评论用户名或正文中只要包含“鲸鱼”就会命中。较宽泛的词（如“主人”“小鱼”）可能过滤正常评论，可在弹窗中删除或替换。

## 安装和使用

### 方式一：加载本地源码（开发者模式）

1. 从 GitHub 下载项目 ZIP 并解压，或使用 Git 克隆仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的**开发者模式**。
4. 点击**加载已解压的扩展程序**。
5. 选择解压后的项目根目录，也就是包含 `manifest.json` 的文件夹。
6. 打开或刷新 Bilibili 视频/番剧页面；扩展匹配 `www.bilibili.com/video/*` 和 `www.bilibili.com/bangumi/*`。

### 方式二：使用打包 ZIP

1. 从仓库的 [`dist/`](dist/) 目录下载 [`fatfish-disaster-blocker-v2.2.0.zip`](dist/fatfish-disaster-blocker-v2.2.0.zip)。
2. 将 ZIP 解压到一个固定目录。
3. 在 Chrome 打开 `chrome://extensions`，打开开发者模式。
4. 点击**加载已解压的扩展程序**，选择 ZIP 解压后包含 `manifest.json` 的文件夹。

Chrome 的“加载已解压的扩展程序”需要文件夹，不能直接选择 ZIP。解压后的文件夹不要删除或移动，否则扩展会失效。打包文件与源码版本一致，当前扩展版本为 2.2.0。

### 设置过滤规则

点击 Chrome 工具栏中的**鱼灾屏蔽助手**图标：

- **启用过滤：** 暂停或恢复所有过滤。
- **隐藏等级低于 3 级：** 单独控制等级过滤。
- **匹配回复内容和用户名：** 单独控制关键词过滤。
- **关键词：** 修改需要匹配的词，多个词用逗号或换行分隔。输入后自动保存。

如刚安装后工具栏没有显示图标，可点扩展程序拼图按钮并将扩展固定到工具栏。

## 更新扩展

### 从源码更新

1. 下载新版源码并放在原来的扩展目录（或重新选择新版目录）。
2. 打开 `chrome://extensions`。
3. 在“鱼灾屏蔽助手”卡片上点击重新加载按钮。
4. 刷新已打开的 Bilibili 视频页面。

升级时扩展会把新版默认关键词并入已有关键词一次，并保留此前自定义的词。之后你在弹窗删掉的词不会在每次启动时自动加回来。

### 从 Chrome Web Store 发布

本项目目前以未打包扩展源码形式提供。维护者可按 Chrome Web Store Developer Dashboard 的当前流程创建开发者账号、上传扩展 ZIP、填写商店资料并提交审核。审核通过后，用户可通过商店安装和接收更新。商店政策和发布要求可能变化，请以 Dashboard 的提示为准。

## 本地开发

本扩展使用 Chrome Manifest V3，没有构建步骤和第三方运行时依赖。修改 `content.js`、`content.css` 或弹窗文件后，在 `chrome://extensions` 重新加载扩展，再刷新 Bilibili 页面。

目录结构：

```text
manifest.json       扩展清单、权限、页面匹配规则和图标声明
content.js          评论扫描、等级/关键词判断、动态更新处理
content.css         隐藏样式和页面状态提示
popup.html          工具栏弹窗结构
popup.js            设置加载、关键词编辑和自动保存
popup.css           弹窗样式
icons/              16、32、48、128 像素扩展图标
dist/               可下载的 ZIP 发布包
LICENSE             MIT License
```

## 常见问题

**评论没有被过滤？**

- 确认扩展已启用，且弹窗中的对应过滤规则已勾选。
- 更新扩展后，在 `chrome://extensions` 重新加载，再刷新 Bilibili 页面。
- 检查页面右下角状态提示。扩展只处理它能识别的评论组件；B 站页面结构改变时可能需要更新适配。
- 等级信息识别不到时，不会按等级规则隐藏；可以使用关键词规则补充过滤。

**正常评论也被隐藏了？**

从弹窗删除过于宽泛的关键词，或关闭关键词规则。关键词只需从用户名或正文中任一处匹配就会隐藏。

**如何确认设置已经保存？**

在弹窗修改选项或关键词后会自动保存；弹窗状态区域会短暂显示“已保存”。

## 权限与隐私

- `storage`：保存过滤开关和关键词。
- `https://www.bilibili.com/*`：只在匹配的 Bilibili 视频/番剧页面运行内容脚本。
- 过滤在浏览器本地执行。扩展代码不会将评论、用户名或设置发送到外部服务器。
